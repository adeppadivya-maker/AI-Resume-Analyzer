# AI Resume Analyzer

An AI-powered web application that analyzes a resume against a job description.

## Features

- Upload resume PDF
- Extract text from resume
- Detect technical skills
- Compare resume with job requirements
- Identify matched skills
- Identify missing skills
- Calculate resume match score
- Calculate NLP similarity score
- Provide learning recommendations

## Technologies Used

- Python
- Flask
- HTML
- CSS
- PyPDF
- Scikit-learn
- TF-IDF
- Cosine Similarity
- Git
- GitHub

## How It Works

Resume PDF
↓
Text Extraction
↓
Skill Detection
↓
Job Description Analysis
↓
Skill Matching
↓
NLP Similarity
↓
Final Match Score
↓
Learning Recommendations
